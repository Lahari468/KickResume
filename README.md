#  KickResume —Resume Builder with Templates

KickResume is a full-stack **MERN web application** developed as part of a summer internship at **Edubot Technologies**.  
It enables users to create, edit, and download **professional resumes** using customizable templates — now enhanced with an **AI-based summary generation API**.


## 🚀 Features

### 🧩 Core Functionalities
- User registration and login with **JWT authentication**
- **Dynamic resume builder** with real-time preview
- **Multiple professional templates** to choose from
- **Auto-save** functionality to prevent data loss
- **PDF export** using jsPDF and html2canvas
- **AI Summary Generator** – automatically creates a professional summary based on user input
- **Template switching** without data loss
- Fully **responsive and modern UI** with Tailwind CSS


## ⚙️ Tech Stack

| Layer | Technology Used |
|-------|------------------|
| **Frontend** | React.js, Tailwind CSS, React Router, React Hook Form, Yup |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB Atlas (Mongoose ORM) |
| **Authentication** | JWT (JSON Web Token), bcrypt for password hashing |
| **AI Summary API** | Custom REST API using OpenAI integration for generating professional summaries |
| **Version Control** | Git & GitHub |
| **Testing Tools** | Postman, Browser DevTools |
